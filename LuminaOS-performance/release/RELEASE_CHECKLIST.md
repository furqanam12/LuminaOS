# LuminaOS 1.1 release validation checklist

Use this file as the go/no-go record for the 1.1 “Aurora Update 1” release. Source-level checks are already complete. Every item marked **[GUEST]** requires a built ISO and a booted LuminaOS VM; those items are deliberately not marked complete in this package.

## 0. Current status

| Area                             | Status       | Evidence                                                       |
| -------------------------------- | ------------ | -------------------------------------------------------------- |
| Source implementation            | **Complete** | Combined source tree under `src/`, `system/`, `tools/`         |
| Automated Python/syntax tests    | **Pass**     | `test-features.py`, `test-installer.py`, `test-performance.py` |
| Automated desktop behavior tests | **Pass**     | `test-performance.js`                                          |
| ISO build                        | **Pending**  | Must run on Linux with >= 8 GiB free disk                      |
| Guest VM acceptance              | **Pending**  | See `QA_MATRIX.md`                                             |
| Release sign-off                 | **Pending**  | See `SIGNOFF_TEMPLATE.md`                                      |

## 1. Pre-build

- [ ] Source archive unpacked to a clean directory.
- [ ] Linux x86-64 host or WSL environment available.
- [ ] At least 8 GiB free disk space on the build filesystem.
- [ ] Build dependencies installable with sudo.
- [ ] Source tests pass:
  ```bash
  python3 tools/test-features.py
  python3 tools/test-installer.py
  python3 tools/test-performance.py
  node tools/test-performance.js
  ```
- [ ] `build.sh` reports `VERSION="1.1"`.

## 2. Build

- [ ] Run `tools/build-release.sh` or `sudo bash build.sh` from the source root.
- [ ] ISO created as `LuminaOS-1.1-amd64.iso`.
- [ ] `LuminaOS-1.1-amd64.iso.sha256` created.
- [ ] `sha256sum -c LuminaOS-1.1-amd64.iso.sha256` passes.
- [ ] ISO size is plausible and not truncated.
- [ ] `release/build-manifest.json` generated by the wrapper script.

## 3. Live ISO boot **[GUEST]**

- [ ] GRUB menu appears with Lumina theme.
- [ ] “Start LuminaOS” boots to LightDM and automatic `lumina` sign-in.
- [ ] “Start LuminaOS (safe graphics)” boots to a usable desktop.
- [ ] Live user has a working Desktop folder.
- [ ] Desktop shows **Install LuminaOS**, not a generic Calamares filename.
- [ ] Desktop, dock, top bar, Control Centre, and notification centre render correctly.
- [ ] Network and audio controls respond without errors.

## 4. Installer **[GUEST]**

- [ ] Desktop installer shortcut launches Calamares.
- [ ] Welcome → **Install LuminaOS** also launches Calamares.
- [ ] Calamares branding and slides show LuminaOS.
- [ ] Installation to a virtual disk completes.
- [ ] Installed system boots without the ISO attached.
- [ ] Installed GRUB menu contains **LuminaOS (safe graphics)**.
- [ ] `sudo update-grub` does not duplicate or corrupt menu entries.

## 5. First-run setup **[GUEST]**

- [ ] Setup opens automatically once after first installed sign-in.
- [ ] Password change works when requested.
- [ ] Device name change works.
- [ ] Time-zone change works.
- [ ] Theme / accent / performance preset changes are saved.
- [ ] Store essentials can be opened.
- [ ] Installed-system checks show green status.
- [ ] Finish writes `~/.config/lumina/setup-complete`.
- [ ] Setup does not reopen on the next login.
- [ ] Setup can be reopened from Settings → Accounts and Help.

## 6. Performance preset **[GUEST]**

- [ ] Settings → System → Performance opens.
- [ ] Balanced restores effects; VM / low-power removes them.
- [ ] Motion, transparency, magnification and shadow toggles persist after sign-out.
- [ ] Compositing remains enabled; no black panels appear.
- [ ] Run `tools/benchmark-performance.py` in Balanced and low-power modes and archive both JSON outputs.

## 7. Accessibility **[GUEST]**

- [ ] Settings → Accessibility opens.
- [ ] Interface scale changes built-in app UI without breaking shell hit regions.
- [ ] High contrast is readable in dark and light themes.
- [ ] Strong focus shows a visible keyboard outline.
- [ ] Tab / Shift+Tab / Enter / Space work in common controls.
- [ ] Reduced-motion mode stops repeating animations.

## 8. Command palette **[GUEST]**

- [ ] Ctrl+K opens the command palette.
- [ ] Search matches apps, settings and actions.
- [ ] Arrow keys and Enter select and run a result.
- [ ] Escape closes the palette.
- [ ] “Show commands” in Settings → Accessibility opens it.

## 9. File Explorer **[GUEST]**

- [ ] Undo / redo works for create, rename, copy, move and trash operations.
- [ ] Split view opens, navigates independently and accepts drag-and-drop.
- [ ] Paste conflict offers Keep both / Replace / Skip.
- [ ] ZIP and TAR archives extract.
- [ ] ZIP creation works.
- [ ] Permissions dialog reads and applies octal modes.
- [ ] Ctrl+L opens path editing.
- [ ] Trash restore works after undo.

## 10. Notifications **[GUEST]**

- [ ] Notification action buttons appear when supplied.
- [ ] Snooze silences banners for 15 minutes.
- [ ] Quiet hours work across a day boundary.
- [ ] Per-app rules for Normal / Silent / Off work.
- [ ] Focus toggle and scheduled focus do not conflict unexpectedly.

## 11. Compatibility **[GUEST]**

- [ ] Compatibility Wizard opens from Settings and Help.
- [ ] Environment checks reflect Wine / Flatpak / Waydroid state.
- [ ] Wine setup and Wine settings launch.
- [ ] Store opens from the Flatpak card.
- [ ] Live session correctly reports Android support as unavailable.

## 12. Final release

- [ ] All blocking defects fixed or explicitly accepted.
- [ ] QA matrix completed and attached.
- [ ] Sign-off template completed.
- [ ] ISO and checksum published together.
- [ ] Release notes published.
- [ ] Source archive published for reproducibility.

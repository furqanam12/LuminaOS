2. Windows programs (.exe, .msi, .bat)

Wine and Proton run many Windows desktop applications and games with near-native speed. Double-click any .exe in Files to start.

3. Kali Linux Suite & Security Terminal

Run Kali Linux penetration testing and security tools (Nmap, Wireshark, Metasploit, Burp Suite, John) with dedicated Kali terminal.

4. Flatpak, AppImage, Snap & RPM Linux apps

Flatpak extends the Lumina Store with thousands of sandboxed Flathub apps. AppImages run portably with zero installation.

5. macOS applications (.dmg, .pkg, Mach-O)

macOS apps use Apple Cocoa and Mach-O formats. LuminaOS provides DMG extraction, Darling command-line support, and one-click Linux native equivalents.

6. Android applications (Waydroid)

Waydroid runs in a nested Weston Wayland window on the Lumina X11 desktop. It needs binder kernel support and an installed system. Android-x86 compatible APKs work best; ARM-only apps are not supported natively.
